\subsection{Per-case execution contract}
\begin{enumerate}
\item Validate the registered input, source identity, numeric parameters and expected geometry.
\item Start a fresh run with explicit stimulus, handshake disturbance and finite watchdogs.
\item Capture actual transfers before comparison; preserve raw results when a checker fails.
\item Compare values and protocol invariants, then require the complete tail and expected counters.
\item Emit a machine-readable receipt. Keep failed and superseded attempts alongside successful attempts.
\end{enumerate}

\page{Bug case study: signed rounded shift}
The C++ reference helper returned zero whenever the unsigned shift was at least 63. That shortcut violated its signed 64-bit nearest-rounding contract with ties away from zero. The defect was reproduced before changing the helper or its tests.
\fig{rounding}{Actual old and repaired executable responses for four retained witnesses. The exact expected values come from integer reasoning and the independent checker.}{2.9in}
\subsection{Repair and domain argument}
For $1\leq s\leq63$, let $m=|v|$ in an unsigned representation and $b=2^{s-1}$. Then $m\leq2^{63}$, $b\leq2^{62}$, and $m+b\leq3\cdot2^{62}<2^{64}$. The magnitude-plus-bias operation is representable, including \texttt{INT64\_MIN}. At $s=64$, only \texttt{INT64\_MIN} reaches a half and rounds to $-1$. Above 64 every input rounds to zero. Shift zero returns the input unchanged.
\begin{lstlisting}[language=C++,caption={Production boundary handling; the existing magnitude path follows.}]
if (shift == 0U) return value;
if (shift >= 64U) {
    return shift == 64U &&
        value == std::numeric_limits<std::int64_t>::min()
        ? -1 : 0;
}
\end{lstlisting}
The related arithmetic-floor shift was inspected and independently tested; it needed no change. Frozen expected artifacts and RTL were preserved. The repaired full-length threshold-zero reference reproduced the registered Y and canonical bins exactly.
\evidence{\epath{reference/source_changes.patch}; \epath{reference/arithmetic_attempt01/report.json}; \epath{reference/arithmetic_attempt01/old_binary_negative_control.json}.}

\item The physical artifact auditor rejected nine deliberately corrupted cases before trusting positive raw-data results.

\end{itemize}

\subsection{Application and performance limits}
The current downstream application is a bounded spectral monitor. No reduction in YAMNet inference computation, power, or CPU cost has been demonstrated. HPS service durations and FPGA cycle registers include feeding, draining and stalls. They are not isolated FFT or core compute latency.
For monitor records, quality and byte comparisons use their original 5 s or 5.12 s support where applicable. Zero padding to an 8 s physical epoch must not inflate a reduction claim. The plotted flute recording already spans the full 8 s input support.

\subsection{What a technical interview can inspect}
