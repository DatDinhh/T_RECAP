\subsection{Failures retained and resolved}
Early UVM harness attempts exposed unsupported multidimensional class-array file loading, start during memory initialization and a one-bit completion flag interpreted as signed decimal. These were verification-environment defects. The accepted harness loads compatible fixture arrays, waits for initialization and exports an integer completion flag. No DUT source changed. During the registered matrix, the simulator later terminated with a startup segmentation fault before DUT execution for seed 7. One explicit relaunch succeeded; the failed attempt, selected replacement and source/compile identities remain separate.

The first reduced FIFO induction attempt timed out. ABC PDR subsequently proved the same exact-order contract. Early mask attempts also exposed a frontend invocation error and an omitted package dependency. More substantially, internal symbolic registers were lowered to undefined port connections rather than shared symbolic inputs. This caused a spurious stall failure and an unreachable recovery cover. Explicit unconstrained top-level input ports repaired the harness/frontend interface. An independent review checked the lowered model, retained assertions/covers and unchanged reset assumption. The accepted mask proof did not obtain its result by restricting legal traffic or modifying the DUT.

\subsection{Checker qualification}
The UVM negative simulation mutates one expected waveform value. Acceptance requires the intended \texttt{Y\_GOLD\_MISMATCH} fatal message and nonzero simulator exit. The three formal negatives deliberately assert that a FIFO never fills, a rounding operation never saturates and the mask never produces valid output. Their labeled counterexamples exercise the corresponding tool/frontend failure paths. The reduced FIFO safety proof uses ABC PDR while its negative control uses SMT bounded checking.

Independent review also mutates the published package and recorded traces. Four UVM package mutations and ten observation/coverage mutations must be rejected, while both unmodified baselines pass. The formal publication checker separately accepts one unchanged baseline and rejects 12 mutations, including rehashed but inconsistent outcomes. These controls test admission, missing/extra records, numerical/order checks and receipt reconciliation. They are checker tests, not additional solver jobs, and do not establish detection of every possible defect.
