# Executed UVM evidence

The accepted campaign contains 12 completed epochs across seeds 1, 7 and 20261017, including three immediate reset-recovery epochs, plus three separately recorded aborted prefixes. Completed totals are 12288 PCM inputs, 18432 source tokens, 18432 Y outputs, 13932 canonical taps and 94440 packet bytes. All values, order, geometry, final metrics and required observed flow-control events passed UVM scoreboarding and independent trace readback. Each completed epoch has one deliberately held final Y transfer; the campaign observes 516 hold cycles in total.

This is an **explicit recovered campaign**, not an uninterrupted default runner PASS. The original three-seed runner completed seed 1, then the simulator crashed at seed 7 startup with SIGSEGV and exit 211 before UVM/DUT loading. The original FAIL summary and crash transcript are included in `preserved_startup_failure`. One separately recorded, bounded seed 7 relaunch with unchanged sources and compiled library succeeded. Seed 20261017 used a fresh build directory. The root cause of the isolated startup crash is unknown; no cache diagnosis or guaranteed workaround is claimed.

`recovery_manifest.json` records the selected receipts and original hashes. The optional `../assemble_recovery.py` does not launch or retry a simulator. It accepts only this tightly specified infrastructure failure class, validates each build's successful compile receipt and exact source/library/configuration binding, checks copied compiled inputs again, and recomputes the complete selected matrix. It cannot convert a DUT mismatch or a missing epoch into PASS. The default `../run.py` still fails on any unexpected simulator exit. Full local traces and build libraries are required to reassemble a recovery; they are not included in this public evidence subset.

The deliberate expected-Y mutation executed in the real UVM environment and produced exactly one `UVM_FATAL [Y_GOLD_MISMATCH]`, zero UVM errors and simulator exit 1. It did not change admitted reference files or the DUT. `postchecker` separately records a real-capture positive control and ten isolated trace/coverage mutations rejected by the Python reconciler. `package_controls` records one positive and four expected package-integrity rejections. These Python controls are not additional DUT simulations.

`seed_1/timing.csv` contains actual sampled rising-edge observations around reset, early spectral taps, and final Y hold/release. Its unit is ns, with a 10 ns simulation clock. Rows outside those selected windows were not captured; gaps must not be presented as continuous waveform samples. This is not a physical board timing measurement.

The official bundled Accellera UVM 1.2 library, all DUT/fixture/coefficient sources, harness and runner are hash-bound in `source_manifest.json`. Each accepted seed report names its `compilation_id`; `compilations` retains both original build manifests and successful compiler receipts. Simulator/compiler warnings and the DPI/Starter limitations are retained in `transcripts`. Functional checks use deterministic UVM sequences and procedural observed counters, with no constrained-random, covergroup, code-coverage percentage or certification claim.

Public JSON and transcripts have only documented path/session sanitization. `export_lineage.json` binds original and exported file hashes. CSV and JUnit XML exports are byte-preserving. Hash fields within original receipts refer to their original local artifacts; use export lineage to locate the corresponding public sanitized artifact hash.
